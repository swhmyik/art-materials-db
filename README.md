# 絵の資料庫 (Art Materials DB)

PC専用の絵の資料・自分の作品の管理ツールです。NAI Matrix の考え方（画像＋タグ＋日付で探す、ローカル保存、ZIPバックアップ）を、絵の資料用にシンプルにしたものです。

## 特徴

- サーバーなしの静的サイト（HTML / CSS / JavaScript のみ）
- 画像とメモは PC のブラウザの IndexedDB にだけ保存され、外部サーバーへアップロードされません
- マトリクス表ビューなし、NovelAI 用の項目（プロンプト / シード / サンプラーなど）なし、NSFW 切替なし、スマホ UI なし
- サムネイル（最大 320px の WebP）を別に作るので、一覧が軽いままです。一覧は 100 件ずつ「もっと表示」で読み込みます

## 使い方

1. `index.html` を PC のブラウザ（Chrome / Edge 推奨）で開きます。ローカルで開くだけで動きます。`python -m http.server` などで配信して開くこともできます。
2. 「＋ 画像を追加」またはドラッグ＆ドロップで画像（PNG / JPG / WebP / GIF）を登録します。作成日はファイルの更新日が使われます。
3. 左のサイドバーで検索します。キーワード（タイトル・メモ・タグ・キャラ）、タグの AND 絞り込み、キャラクター、期間（開始日〜終了日）、★お気に入りのみ、並び替えができます。
4. サムネイルをクリックすると詳細画面が開きます。タイトル・キャラクター・タグ（カンマ区切り）・メモ・お気に入りを編集すると自動で保存されます。「同じ作成日を検索」でその日の画像だけ表示できます。
5. 削除は詳細画面の「削除」ボタンから。確認ダイアログが出ます。

## バックアップ（重要）

データはこの PC のブラウザの中にしかありません。ブラウザのデータを消すと消えます。定期的に ZIP 保存をしてください。

- **ZIP保存 (元画像込)**: `metadata.json` ＋ 元画像 ＋ サムネイルを ZIP にします。2,000 件または約 3.5GB ごとに `part01` / `part02` … に自動分割します。
- **軽量ZIP**: `metadata.json` ＋ サムネイルだけ。移行・確認用に軽くて速いです。
- **復元**: 保存した ZIP を複数同時に選べます。同じ ID の画像はスキップして重複を避けます。

ZIP 機能には JSZip を CDN（`cdnjs.cloudflare.com`）から読み込んでいます。オフラインで開くと ZIP 保存・復元は使えません。その場合は画面にメッセージが出ます。

## GitHub Pages について

このリポジトリを GitHub Pages で公開する場合、GitHub Free ではパブリックリポジトリで Pages が使えます（0円）。画像やメモ自体は GitHub には上がらず、開いた人のブラウザの中にだけ保存されます。公開は別ステップで行います。
